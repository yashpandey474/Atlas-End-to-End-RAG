# Atlas test chunked data

This directory contains a small synthetic dataset for testing Atlas without downloading external PDFs.

The files use the same chunk-oriented JSON structure expected by the indexing pipeline:

- `atlas-handbook_chunked.json`
- `engineering-notes_chunked.json`
- `fictional-company_chunked.json`

Suggested questions:

```text
What embedding model does Atlas use?
How does Atlas store embeddings?
What is BM25 useful for?
Why would a cross-encoder be used?
What metrics can evaluate retrieval quality?
What services does Northstar Lake provide?
What is Northstar's standard recovery point objective?
What are the three support severity levels?
```

The content is fictional/synthetic and is intended only for software testing.
